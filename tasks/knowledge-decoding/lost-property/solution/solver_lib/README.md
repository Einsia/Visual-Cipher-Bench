# Independent pixel reference solver

Run `python /solution/solve.py --images /app/images --output /work/result.json`.
The optional `--diagnostics /work/trace.json` writes the recognized geometry,
words, directed edges, and dictionary witnesses. Standard output is the same
JSON object as the requested output file. Recognition/ambiguity failures produce
an `error` object and exit status 1.

Only PNG pixels from `--images` supply puzzle-specific information. The program
reads its own general knowledge assets in this directory.
The solver runs when this directory and solve.py are the only files mounted
at `/solution`.

## Recognition

1. Composite PNG transparency onto white, crop the visible ink, and normalize
   the ink width. This removes absolute page position and overall scale.
2. Locate repeated dash sequences and their matching vertical borders. Read
   the contents using all upper/lowercase DejaVu Sans letter templates; no
   vocabulary of page labels or predetermined box positions is supplied.
3. Find compact connected object outlines and compare their normalized shape
   with the generic object templates. Group the remaining small components into
   printed words.
4. Find solid rectangular frames from long horizontal strokes and corresponding
   vertical sides. Detect triangular arrowheads by erosion; estimate each shaft
   direction from its pixels and follow its thinned stroke. Continue straight
   through crossings, turn at connected elbows, and bridge only the small gaps
   introduced by removal of frame strokes. A nearby but disconnected parallel
   arrow is never treated as a junction.
5. Associate the two ends of each traced arrow with the detected entities.
   Infer arrow-order concatenation from the asymmetric printed lexical pair.
   No completed extraction example is required. Locate the sole unresolved
   extraction frame by containment and its outgoing arrow; it contains exactly
   two word boxes and one directed internal edge.

## Language reasoning

The domain is common English vocabulary intersected with a general WordNet
lexicon. Compounds are generated by trying *all* splits of *all* normalized
WordNet headwords, including spaced and hyphenated headwords. Proper-name-only
headwords are excluded based on their original case in the dictionary, not on
any puzzle-specific blacklist. Arc consistency and backtracking solve the
entire recovered directed graph.

Dictionaries do not list every separately written expression as a headword.
If necessary, the solver systematically permits dictionary-gloss phrase
witnesses on zero, then one, then two arbitrary edges. These witnesses are
adjacent words appearing at least twice across the complete WordNet definitions
and examples. No specific edge or word pair is exempted in advance. The first
level admitting a semantically grounded solution must have exactly one complete
assignment; ambiguous inputs fail rather than return a preferred answer.

For an arrow ending in an object picture, the compound must name a kind of that
object according to the complete WordNet noun hypernym graph. Mere spelling is
insufficient: a marine invertebrate with a name ending in “fish” does not match
the pictured vertebrate. This check is applied uniformly to every terminal
object picture, using labels derived from shape recognition. Pictured nouns
used as modifiers are not subjected to that head-category test.

## General knowledge and provenance

* `DejaVuSans.ttf`: the system DejaVu Sans font, the same family used on the
  page, with its generic glyph outlines. Runtime Pillow
  renders the full alphabet, not a set of puzzle words.
  License: `LICENSE-DejaVu.txt`.
* `common_words_20k.txt`: 20,000 general English tokens derived from wordfreq
  3.1.1, with no filtering by clues or expected results. The derived list is
  licensed under CC BY-SA 4.0, not the project's content license. See
  [the provenance and validation notice](LICENSE-common-words.txt),
  [attribution](LICENSE-wordfreq.txt), and
  [the complete license](LICENSE-CC-BY-SA-4.0.txt).
* `wordnet_lexical.txt`, `wordnet_phrases.tsv`, `wordnet_nouns.json.gz`: generated
  uniformly from the complete Princeton WordNet 3.1 `data.*` files. These are
  not curated compound or semantic pair inventories. Every eligible
  dictionary headword, every gloss bigram (with counts), and every noun synset
  with its hypernyms is included. License: `WNDB_License.txt`.
  `build_resources.py` documents and reproduces this transformation offline.
* `icons/*.png`: isolated monochrome outlines of generic objects (an ear of
  corn, a coat, and a fish), taken from the puzzle illustrations and stripped of
  all surrounding page context. The files contain no arrows, text, boxes, page
  coordinates, node IDs, or adjacency information. Human annotations in
  `icons/labels.json` supply ordinary object names and visual synonyms. At run
  time every detected object is compared with every template at its newly
  detected location. These templates are original puzzle artwork; no
  third-party icon assets are included.

The runtime needs Python 3.12, numpy, and Pillow only. No network, OCR service,
external executables, or preinstalled dictionary/font paths are used. Geometric
thresholds describe stroke/object sizes on a normalized image, not positions on
the page. The supported perturbations are page translation and mild
uniform rescaling; substantial occlusion or redrawing may fail explicitly.
