Derivation: request top_n_list('en', 200000) with wordfreq 3.1.1's defaults;
retain tokens for which isascii() and isalpha() are both true, preserving
the supplied order; lowercase; take the first 20,000; serialize one token
per line with LF endings and a final newline. Frequencies are omitted.
No puzzle-specific filtering, additions, or reordering are performed.

This release uses the wordfreq-derived list in place of the earlier
Google-corpus-derived vocabulary. The earlier list is not included and
is not represented as public domain. This change affects a reference-
solver resource only; puzzle images, instructions, answers, grading,
and the evaluated agent's environment are unchanged.

Validation on 2026-11-13: the list was independently regenerated from
the identified wheel and matched byte-for-byte. The unchanged reference
solver, run offline on AWS in the Linux x86-64 / Python 3.12 benchmark
image with this list, returned BACKFIELD. The unchanged task grader
awarded reward 1. This checks the reference solution; it is not a rerun
of the model evaluation.
